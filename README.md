# 連線小遊戲大廳

和朋友輸入同一個暗號就能連線對戰的 HTML 小遊戲，手機、電腦都能玩。

**開始玩：** https://qq79634pp-eng.github.io/Games/

| 遊戲 | 人數 | 說明 |
| --- | --- | --- |
| [井字 OX](ox-online.html) | 2 人 | 三個 O 或 X 連成一線（含斜線）獲勝，每局輪流先手 |
| [1-25 賓果](bingo-online.html) | 2～6 人 | 每人一張亂數盤，輪流選號，最先連成 5 條線獲勝 |

連線使用 PeerJS（WebRTC 點對點），不需要自己架伺服器。
